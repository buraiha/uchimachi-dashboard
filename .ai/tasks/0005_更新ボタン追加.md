# 更新ボタン追加

- Status: completed
- Depends on: none

2026-09-17に仕様とサンプルを確認後、ユーザーの「OK。実装して」に基づき実装した。ローカル検証は完了。外部連携・認証切れの実行経路は一部未確認（末尾参照）。

## 目的と要求

- ダッシュボードメイン画面のタイトル横に更新ボタンを追加する。
- 気の利いたアイコン的なものが欲しい。
- 自動更新機能を削除したのでね。

## 確定仕様

### 配置と見た目

- 通常のダッシュボード（`GET /`、`GET /dashboard`）のタイトル `DASHBOARD_TITLE` のすぐ右隣に、更新ボタンを1個配置する。
- 円を描く矢印のインラインSVGを使った、アイコンのみの丸いボタンとする。外部画像、アイコンフォント、ライブラリは追加しない。
- 操作領域は44×44px以上、アイコンは約20px。既存画面の背景・枠線・アクセント色に合わせる。
- タイトルとボタンを専用の横並び領域に置き、タイトルが長い場合はタイトルを折り返し、ボタンを縮小・画面外にはみ出させない。狭い画面でもタイトルとの隣接関係を保つ。
- マウスホバーとキーボードフォーカスを視覚的に区別できるようにする。常時回転や装飾アニメーションは付けない。
- ネイティブの `<button type="button">` を使用し、`aria-label="ダッシュボードを更新"`、`title="ダッシュボードを更新"` を付ける。SVGは `aria-hidden="true"` とし、Tabでフォーカス、Enter／Spaceで実行できるようにする。

### 更新動作

- ユーザーがボタンを押した場合に限り、`window.location.reload()` で現在のページ全体を再読み込みする。部分更新や新規APIは導入しない。
- 現在のパス（`/` または `/dashboard`）、クエリ文字列、フラグメントを変更しない。特に `max_results` の選択値（10／20／30／40）を維持し、既存のlocalStorageによる表示件数の保存・復元処理を変更しない。
- 既存の `dashboard` ハンドラーを通じ、Google Calendarの予定、予定メモ、伝言、保存済みチャート設定を再取得・再描画する。更新時点の日時に基づいて本日・明日などの区分も再計算する。
- 更新ボタンから設定保存や伝言投稿を行わない。チャート表示・日数の未保存の変更は破棄され、DBに保存済みの設定へ戻る。確認ダイアログや未保存内容の自動保存は追加しない。
- 認証切れ、OAuth未認可、取得失敗時は既存の認証導線・エラー画面を利用する。新しい通知、リトライ、エラー画面は追加しない。
- 更新中の表示はブラウザ標準の読み込み表示を使用する。独自のスピナー、成功通知、最終更新時刻、連打制御は追加しない。
- JavaScriptを前提とし、無効時の専用フォールバックは追加しない。通常のブラウザ再読み込みは引き続き利用できる。

## 守るべき仕様と制約

- `.ai/project.md` にある再読み込み再導入の制約については、このタスクの明示要求に基づき「ボタン操作時だけの手動再読み込み」を対象とする。自動更新は禁止のまま維持する。
- `type="button"` とし、既存の表示件数・チャート設定・ログアウトのフォームを誤送信しない。
- 更新イベントは当該ボタンだけに登録する。ページ表示時や一定時間経過、ウィンドウのフォーカス復帰を契機とする再読み込みを追加しない。
- タイトルのHTMLエスケープ、表示件数の正規化、認証分岐、保存済みチャート設定を維持する。
- 既存データ・認証情報を使った検証や実運用環境の操作を行わない。

## 受け入れ条件

1. 通常のダッシュボードで、タイトル右隣に円形矢印アイコンのボタンが1個表示される。予定・伝言が0件でも表示される。
2. クリック、Enter、Spaceで現在のダッシュボードが再読み込みされ、別のフォーム送信や設定保存が発生しない。
3. `/` と `/dashboard` のどちらでも更新でき、URLと表示件数を維持する。
4. 再読み込み後に予定・伝言・予定メモ・保存済みチャート設定の取得結果が表示される。未保存のチャート設定は保存されない。
5. 利用者認証の有効・無効いずれの描画でも配置が成立し、認証切れや取得失敗は既存の処理に従う。
6. 幅375px・768px・1280pxおよび長いタイトルで、ボタンが潰れたりタイトルや既存操作に重なったりしない。フォーカス位置を判別できる。
7. 更新ボタンに起因する自動更新・タイマー・外部アセット読み込みが追加されていない。
