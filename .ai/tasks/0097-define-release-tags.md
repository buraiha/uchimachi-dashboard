# リリースコミット表示と版タグによる差分管理

- Status: completed
- Depends on: none

## 目的と対象

ユーザー承認に基づき、リリース対象コミットIDの併記、成功時のv形式タグ、履歴更新のコミット・対象ブランチとタグのpush、前版タグからの差分を定義する。対象はAGENTS.md、.ai/common.md、レビュー・taskガイド、.ai/project.md、導入記録、CHANGELOG.md（存在する場合）、本taskと試験結果。

## 制約

今回は手順と未確定表示の整備のみ。既存VERSION・タグ・過去履歴・アプリは変更せず、コミット・push・リリースは実行しない。自己参照を避けるため、履歴記録用コミットではなく、実際にリリースしたコードのコミットへタグを付ける。

## 検証

[試験結果](0097/test-results.md)。共通定義一致、旧ルール残存なし、対象コミットと履歴コミットの区別、未確定表示、版・タグ・過去記録保持、文書形式を確認する。

## 実施結果

手順を現行本文へ統合し、未リリースのエントリはコミットID・タグ間差分を未確定とした。実際のタグ作成・Git操作・リリースは未実施。
