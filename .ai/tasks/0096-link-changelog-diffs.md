# チェンジログのコミットIDと差分リンク

- Status: completed
- Depends on: none

## 目的と対象

ユーザー依頼に従い、過去変更には製品バージョンの代わりにコミットIDを表示し、各エントリ末尾へGitHub差分リンクを付ける。対象はCHANGELOG.md（存在する場合）、.ai/common.md、導入記録、本taskと試験結果。バージョン・アプリ・過去task・コミット・push・リリースは変更しない。

## 方針

過去の各変更は該当コミットの第一親と比較する。今後の版エントリは前版からの比較を使う。未コミット・比較元不明・remote未設定ではリンクを捏造せず未確定と記録する。Git参照はローカル検証し、GitHubでの到達性・push済み状態は未確認とする。

## 検証

[試験結果](0096/test-results.md)。ID・親コミット・originとURL・エントリ件数・版番号不変・文書形式を確認する。

## 実施結果

過去変更5点にコミットIDと第一親からのGitHub比較リンクを付与。初期登録は未コミットのため差分未確定とし、今後の版間比較規則を共通原本・導入先で統一した。
